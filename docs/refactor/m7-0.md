# M7-0: multi-stream contract

> M7 の最初の production slice を、有限・static な MP4 file-to-file job に限定して確定する。
> この文書は M7 固有完了条件と R-17 traceability の正本である。

## 目的と境界

M7 は、unfragmented MP4 を RandomRead+StableSize source から読み、複数 track を保存優先で
RandomWrite sink へ remux する。音声は必要な時だけ PCM Binding を通し、decode Binding のない
video/subtitle/data track は packet copy する。入力一つ・出力一つの既定 job は全 track を Inspect 順で
保持し、明示 mapping は既存の exact `job.MapStream` を使う。

MP4 は multi-stream execution contract の最初の公式 consumer である。このために closed media role、
heterogeneous item map、packet 内の stream identity、item ごとの reflection/string lookup を導入しない。

M7 に含めないものは fragmented/sequential MP4 とその spool alternative、rich selector、generic loss DTO、
`ilst` vocabulary mapping/strict mode、graph seek operation、video/subtitle decode、live topology、Endpoint/clock、
stdin/stdout、WASM、`_legacy/` 削除である。これらは [延期する consumer](#延期する-consumer) まで API を作らない。

## 確定した product semantics

### static topology と inspection

Component topology の正本は construction 時の `Spec.Ports` だけである。全 executable Spec は static な
schema、direction、`One`/`Many`、fan-in policy をここへ宣言する。Inspect 後に port 数や port ID を変える
dynamic Shape、`ShapeContext`、instance Shape snapshot は使わない。

MP4 demux は一つの `bytes` input と一つの `Many` `tracks` output を持つ。MP4 mux は一つの `Many`
`tracks` input と一つの `writes` output を持つ。track cardinality と identity は dynamic port ではなく、
同じ logical port に束縛された ordered repeated `stream.Descriptor` で表す。descriptor は canonical
`stream.ID`、open schema ID、optional timeline、property、metadata を持つ。format-specific raw box、
sample-entry state は descriptor 本体に入れず、MP4 inspection が所有する narrow immutable remux provenance
に置く。

`format.Inspection` は Format 固有の typed fact を freeze して Compile へ渡す。mutable value の clone は
`format.Inspection` wrapper が登録時と typed recovery 時にだけ担い、generic plugin trait store を
clone framework にしない。metadata Resolver のような別の prepared value は、その型を所有する package が
immutability を保証する。Inspect、Compile、Open は catalog や mutable Host service を受け取らない。

### logical many edge と typed Router

planner は logical `Many` port の repeated descriptors と resolved mapping から、private runtime connection を
descriptor ごとに一つ作る。各 connection は descriptor、stream identity、route/input ordinal、time base を
Open 前に固定する。public graph/Plan は logical port と repeated `PortDescriptor` を投影し、別の topology DTO を
重複して持たない。

typed `Router[I, O]` は一つの input item を一つの route ordinal へ送る。runtime は ordinal を
`[]typedDelivery[O]` 相当へ一度だけ解決するため、item loop に port string lookup、reflection、`any`
transport はない。同じ track を複数 output へ送る明示 mapping は Router 後段の既存 fan-out と `Fork`
ownership contract が担い、Router 自身は複製しない。

packet/chunk に `stream.ID`、format 名、selector を追加しない。stream identity は descriptor と private
compiled connection に属し、Router ordinal、parser/codec connection、mux input ordinalが保持する。

### MergeFanIn

新しい public `Merger` operator interface は作らない。既存 `flow.Joiner[I, O]` と `MergeFanIn` を使い、
runtime に ordered merge execution を追加する。MP4 mux の Joiner は、runtime が選んだ一つの typed queue
head を受け取る。

MP4 merge に接続できるのは valid timeline と DTS を持つ packet descriptor connection だけである。
untimed Bytes/Writes、asset-level raw box、timeline-less descriptor は merge input ではない。各 non-EOF input
の head が得られてから per-connection time base で DTS を比較し、EOF 後は残る input を drain する。
missing/backward DTS、rescale overflow は fail-closed とする。同時 DTS は resolved mapping order、次に packet
sequence で全順序化する。

### timeline と packet

timeline-less descriptor と timed descriptor を区別する。MP4 track は valid per-track time base を持ち、
packet/chunk は PTS、DTS、duration の known/unknown と known zero を区別する。Chunk を経由する parser path も
timing を失わず、PCM parser は既知 sample timing を投影する。descriptor fingerprint、graph validation、Plan、
private runtime connection は timeline の有無を保持する。

### mapping と保存既定

入力一つ・出力一つで mapping を省略した場合は、Inspect した全 eligible track をその順序のまま map する。
明示 mapping は exact input index、canonical `stream.ID`、output indexを持つ既存 `job.MapStream` に限定する。
存在しない stream、duplicate route、target に表せない明示 mapping は Planning error とする。同じ input track
の複製は明示 mapping のみ許可する。

無指定 path は format、codec、stream order、metadata/raw state を保持し、copy/remux を優先する。PCM Binding は
明示した変換または target requirement に必要な時だけ選ぶ。codec Binding のない video/subtitle/data track は
raw packet copy する。default preserve-all path で保持できないものがあれば、M7 では黙って drop せず Planning を
失敗させる。明示 mapping で選ばなかった track は user intent による除外である。

Plan は repeated descriptors、resolved exact mapping、copy/PCM decision、DTS merge order を表示する。
新しい selector DSL、per-edge solver、generic loss model は作らず、concrete logical connection を既存 solver へ
個別に渡す。

### MP4 I/O と exact boundary

M7 の MP4 input は RandomRead+StableSize、output は RandomWrite を要求し、unfragmented mode だけを実装する。
source/sink capability と選択 mode は既存 Plan boundary へ残す。sequential/fragmented/spool mode をこの slice の
fallback にしない。

unchanged same-format remux は selected sample payload、PTS/DTS/duration、track/mapping order、preservable raw
top-level/track box、sample entry、metadata carrier の byte 列と anchor 内相対順を保持する。file byte identity、
offset、interleave、再生成する既知 box の全体順は exact に含めない。default preserve-all で narrow provenance が
安全に再利用できない場合は Planning error とし、推測して drop または stale anchor を再利用しない。

### Queue policy

M5 の旧 `QueuePolicy.Window` が兼ねていた二つの意味を分ける。physical queue limit は stream-local span だけを制限する
`Span` とし、item/byte limit とともに buffer/Plan へ投影する。Zip の timestamp alignment tolerance は別の
Zip alignment field/Plan projection へ移す。`MergeFanIn` は Zip alignment を使わず、有限 offline input を正しく
待機する。late/drop/conceal policy は M9 の realtime consumer まで追加しない。

## core と plugin の責任境界

Core/Host/runtime は static `Spec.Ports` と execution binding の一致、descriptor cardinality/identity、route
ordinal、typed ownership、per-connection schema/time base、DTS order/overflow/EOF/cancel、mapping cardinality を
検証する。invalid plugin output で memory ownership や隣接 connection を壊させない。

Format/plugin は Inspect が実 file と一致すること、declared clone が本当に mutable alias を切ること、pure
callback が global state を読まないこと、MP4 box/sample table/provenance が規格上正しいことを担う。Core は
clone callback の意味、catalog access の不在、box 分類の正しさを reflection や sandbox で証明しない。
これらは plugin conformance と規格 fixture で検査する。

## 作業単位と依存順

```text
M7-0 contract
  └─ M7-1 static multi-stream execution
       └─ M7-2 unfragmented MP4 reader/writer/remux
            └─ M7-3 default/exact mapping and PCM binding
                 └─ M7-4 conformance/integration/performance completion
```

### M7-1: static multi-stream execution

Make `Spec.Ports` the sole executable topology, remove dynamic Shape/ShapeContext, keep Format-specific inspection
cloning outside the generic trait store, expand repeated descriptors into private typed connections, add Router and
`Joiner + MergeFanIn`, retain per-connection descriptor/time base, and split queue `Span` from Zip alignment.

### M7-2: unfragmented MP4 remux

Implement MP4 Probe/Inspect, RandomRead+StableSize packetized demux, RandomWrite unfragmented mux, mixed-timescale DTS merge,
and descriptor-external raw/sample-entry provenance. Complete only when PCM plus unknown video/subtitle/data tracks
roundtrip without decode and default raw state is exact or Planning fails.

### M7-3: mapping and PCM Binding

Resolve no-map 1×1 preserve-all and exact `job.MapStream`, project repeated descriptors/mapping/decisions to Plan,
reuse the existing solver per concrete logical connection, and select PCM codec paths only when required.

### M7-4: completion verification

Extend public testkit and integration without an MP4-only private path. Cover unfragmented multi-track files,
per-track timescales, unknown video/subtitle/data, unknown boxes/sample entries, exact/default mapping, cancel/EOF,
ownership, and performance. Required conformance must not be silently skipped.

## 延期する consumer

| capability | earliest owner | consumer required before API |
|---|---|---|
| MP4 `ilst` mapping、generic loss DTO、strict metadata | M8 | migrated metadata encoding that needs structured predicted/actual loss |
| finite graph seek、preroll/reset/result | M8 | MP4 plus migrated MP3/FLAC/decoder path |
| rich selector syntax/language/disposition surface | M9 | CLI/WASM/HTTP or multi-input/output surface |
| fragmented/sequential MP4、spool alternative | M9 | stdin/stdout、remote or streaming surface |
| late/drop/conceal/realtime alignment | M9 | Endpoint clock/live consumer |

延期項目は M7 API へ placeholder field、empty DTO、unused policy として先行追加しない。

## Performance gate

M7 fast path は `MP4 demux → per-track copy or typed PCM path → DTS merge → MP4 mux` である。route table、
mapping、descriptor connection は Open 前に作り、Run は typed closure/ordinal と queue head だけを使う。

[performance](performance.md#開発時の性能回帰方針) に従い、同一 process/fixture で unchanged multi-track remux と
PCM-bound path を AB/BA 測定し、Open と steady-state Run を分けて `-benchmem` を取る。Run に新しい mandatory
per-item allocation を認めず、user-visible time または無視できない allocation が概ね 2 倍以上悪化した場合は調査する。

## M7 completion conditions

- M7-C01〜M7-C11 が production consumer と negative case を持つ。
- `standard.NewHost()` で unfragmented RandomRead+StableSize/RandomWrite MP4→MP4 default remux、exact `MapStream`、
  PCM Binding、unknown video/subtitle/data raw copy が実行できる。
- Plan が ordered repeated descriptors、resolved mapping、copy/PCM decision、DTS merge order、I/O capability を示す。
- default preserve-all は selected sample/timing/order/raw provenance を黙って失わず、保持不能なら Planning error になる。
- conformance corpus、full module test、generator、docs check、performance gate が green である。
