# M3-2 実装指示書: 共通 vocabulary と skeleton の metadata 経路

M3-2 のうち、`media/metadata` の core（`Blob`、`Key`、`Document`/`Builder`、`Binding`、`Mapping`）と `stream.Descriptor.Metadata` は実装済みである。この文書は残る 2 件を扱う。

前提、必読、スコープ境界、中断条件は [m3-1.md](m3-1.md) と同じである。`core`、`sdk`、`plugin/<family>`、`cli`、`bindings`、`example` の production code には触れない。

contract の意味は [media.md](../media.md#metadata-document) を読む。この文書はそこに書かれていない制約だけを述べる。着手前に `media/metadata` の godoc と test を読み、既存 API の形に合わせる。

## 1. `media/tag`

[media.md](../media.md#open-key-と共通-vocabulary) の共通 vocabulary を `media/tag` として新設する。`metadata.DefineKey` を使うだけの package であり、core を変更しない。第三者が同じ方法で独自 key を足せることが要件なので、`tag` に特権的な仕組みを持たせない。

対象 key は現行実装が実際に運んでいるものに限る。`plugin/id3`、`plugin/vorbiscomment`、`plugin/wave/internal` の RIFF INFO が読み書きしている項目を調べ、その和集合を出発点にする。**推測で key を増やさない。** 現行にない項目は、それを必要とする format を移す M6/M8 が足す。

値型で判断が要るのは次の 2 つである。

- **日付**: 現行 `sdk/date` は年のみ、年月のみ、完全日付を区別する部分日付を持つ。[inventory.md](../inventory.md) はこれを `tag.Date` の移行先としている。`time.Time` に潰すと「1985 年」と「1985-01-01」が区別できなくなり、metadata の roundtrip が壊れる。現行の semantics を保つ。実装は移送でよいが、`sdk` を import せず `media/tag` 内に置く。
- **画像**: `metadata.Blob` を payload に使う。`[]byte` を持たせない。artwork が entry 複製ごとに copy されないことが M3 の完了条件であり、`Blob` がその保証である。

reference 型を値に持つ key は `metadata.DefineKey` の clone 宣言が必須である。`Blob` は immutable なので clone は値を返すだけでよいが、宣言は省略できない。

`tag` は公式 plugin を import しない。test も同様に、第三者相当の fixture で行う。

## 2. walking skeleton の metadata 経路

[media/foundation_test.go](../../../media/foundation_test.go) の walking skeleton に metadata を足す。既存の `bytes → chunk → packet → frame → packet → chunk → bytes` を壊さない。

- trivial な metadata encoding を fixture として定義し、carrier payload から `metadata.Document` を作り、同じ carrier へ書き戻せることを通す。
- `metadata.Bind` の宣言を `plugin.Set` へ入れ、`host.New` が declaration conflict と target の実在を検査する経路を通ることを確認する。codec binding と同じ口に乗るので、新しい仕組みは要らない。
- **raw preservation を検査する。** encoding が解釈できなかった payload が `RawBlock` として保持され、書き戻した carrier に元の byte 列がそのまま現れること。これが [C10](../decisions.md) の「黙って捨てない」を skeleton が証明する箇所である。
- 同一 key の複数値と、その順序が roundtrip で保たれること。
- 時刻に沿って変化する metadata が static `Document` ではなく `schema.Define` の typed event として宣言できることを、別の test で示す。event を運ぶ実 component は要らない。宣言と port 接続まででよい。

loss report の surface 表示は M7 の担当なので実装しない。encoding が表現できない entry を検出できることまでを示す。
